# Учётная запись Token Seller для DeepSeek Harness

Пакет подключает DeepSeek Harness к сервису **Token Seller** (федота.рф):
вход по почте и паролю, получение ключа, баланс и история вызовов прямо в
настройках.

Здесь лежит **только собранный пакет**. Исходники живут отдельно и в этот
репозиторий не попадают.

## Установка

Требуется DeepSeek Harness `0.2.0-rc.2`.

1. Откройте **Настройки** → **Plugins**.
2. Нажмите **Add plugin** и вставьте адрес репозитория:

   ```
   https://github.com/konstantin-vysitsky/fedot-token-seller-account
   ```

3. Нажмите **Install** и перезапустите приложение.

### Установка из командной строки

То же самое без интерфейса, если удобнее:

```powershell
dsh plugin --profile <профиль> add "https://github.com/konstantin-vysitsky/fedot-token-seller-account"
```

Профиль `desktop` принадлежит приложению, и командная строка его не примет.
В приложении пользуйтесь кнопкой **Add plugin**.

## Что происходит после установки

1. Откройте **Настройки** и найдите раздел **Token Seller**.
2. Войдите своей почтой и паролем от федота.рф.
3. Панель сама получит ключ, положит его в хранилище секретов под именем
   `TOKEN_SELLER_API_KEY` и пропишет маршрут моделей.

Штатный маршрут DeepSeek при этом **не выключается**: маршрут Token Seller
дописывается рядом. Если что-то с сервисом не так, чат продолжит работать на
штатном провайдере. Ключ настраивать руками не нужно, в поля он не выводится.

Все обращения к сервису идёт хост-половина пакета: браузер к Token Seller не
ходит.

## Что внутри

| Файл | Что это |
|---|---|
| `lib/index.js` | хост-половина: вход, ключ, баланс, все HTTP-вызовы к сервису |
| `lib/client.js` | браузерная половина: панель личного кабинета в настройках |
| `cordis.patch.yml` | слой, который вставляет пакет в дерево конфигурации |

Поле `dsh.bundle` в `package.json` делает пакет полноценным слоем. Благодаря
ему пакет ставится сам по себе, без общего сборочного слоя.

Адрес сервиса — настройка слоя. По умолчанию боевой домен
`https://xn--80ahc1bui.xn--p1ai` (`федота.рф`). Переменная окружения
`TOKEN_SELLER_BASE_URL` подменяет адрес на стенд при отладке.

## Ограничения

- **Разбивка расходов вырезана из этой версии.** В панели только баланс и
  история вызовов. Разбивки по проектам, чатам и запросам здесь нет — она
  слишком нагружала систему на длинной истории.
- **Версия привязана к харнессу.** Пакет объявляет совместимость с
  `0.2.0-rc.2`. На другой версии Harness откажет в установке.
- **Обновления вручную.** Автоматических обновлений нет: чтобы поставить новую
  версию, пакет надо удалить и установить заново.
- **Нужен доступ к npm-реестру.** Пакет тянет из реестра две зависимости
  (`@deepseek-ai/dsh-anonymous-user-id` и `zod`). Без доступа к реестру
  установка упадёт.

## Сборка

Файлы в `lib/` собраны из исходников скриптом `scripts/build.mjs` в рабочем
репозитории модулей. Здесь они лежат готовыми: так ученику не нужны ни Node,
ни pnpm, ни TypeScript. Карты кода (`.map`) в репозиторий не положены: они
весят больше самого кода, а харнесс их отсутствие переносит.
